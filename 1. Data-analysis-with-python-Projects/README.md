# Data-analysis-Projects

# 📊 Data Analysis Portfolio

This repository represents **the foundation of my journey into Data Science and IT**. Before moving into advanced areas like Machine Learning, MLOps, and AI systems, I built my core analytical thinking through **hands-on data analysis projects** that mirror real-world business problems.

The goal of this repository is simple:

> **Transform raw data into meaningful insights using industry-relevant tools and workflows.**

---

## 🧠 What This Repository Focuses On

Every project in this repo is designed around the **three core pillars of Data Analysis**:

1️⃣ **Programming for data** → Python (NumPy, Pandas, Matplotlib, Seaborn)
2️⃣ **Querying structured data** → SQL-based thinking and transformations
3️⃣ **Insight communication** → Business-driven analysis and visualization

Beyond tools, each project emphasizes:

* Problem framing
* Business understanding
* Data storytelling
* Decision-oriented insights

---

## 🛠️ Tech Stack

* **Languages:** Python
* **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
* **Analysis:** Exploratory Data Analysis (EDA), statistical reasoning
* **Data Handling:** CSV-based structured datasets
* **Visualization:** Python-based plots (business-focused)
* **Domain Exposure:** Retail, Telecom, SaaS, Healthcare, Housing, Transportation, Gaming

## 📌 Project Highlights

### 🛒 Instacart Analysis

Customer purchasing behavior analysis to identify demand patterns and product-level insights.

### 📞 Megaline Analysis

Telecom usage and revenue analysis to uncover churn signals and plan performance.

### ☁️ Microsoft SaaS Products Analysis

Feature usage and segmentation analysis to understand SaaS adoption trends.

### 🍽️ Online Restaurant Data Analysis

Order behavior and operational performance analysis for food delivery insights.

### 🏙️ San Francisco Housing Rental Analysis

Rental pricing trends and neighborhood-level dynamics based on census data.

### 🧠 Stroke Analysis

Healthcare data analysis focused on identifying key risk factors and patterns.

### 🚕 Taxi Company Analysis

Demand and operational analytics to support service optimization decisions.

### 📊 Usage Analysis of Customers

Behavior-based customer segmentation and early risk identification.

### 🎮 Video Game Console Sales Analysis

Market lifecycle and regional sales trend analysis across gaming platforms.

## 🎯 Key Learnings

* Data analysis is **not about tools alone** — it’s about asking the right questions.
* Real-world data is messy, incomplete, and requires strong reasoning.
* Business context determines whether an insight is valuable or irrelevant.
* Visualization is storytelling, not decoration.

These projects laid the groundwork for my transition into **Machine Learning, AIOps, and MLOps**, where analytical thinking becomes even more critical.
