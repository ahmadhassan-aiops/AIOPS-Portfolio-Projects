# DreamBooth fine-tuning of Stable Diffusion 2

A technique exercise: teaching Stable Diffusion 2 a new style or subject from a handful of images with DreamBooth,
with and without prior preservation. Built on starter code from a university deep-learning course (the training
loop, data loaders and configuration were completed for the assignment); it is a learning project, not a product.

## What it does

- **Fine-tunes the UNet** of `sd2-community/stable-diffusion-2` (the text encoder and VAE stay frozen) on a few
  instance images tied to a rare token, `purcs`, for example "a purcs claude-monet".
- **Prior preservation (optional):** before training, the base model generates images of the general class ("a
  claude-monet"); training then mixes them in with their own loss term, so the model learns the new concept without
  forgetting what the class looks like.
- **Evaluation:** before, during and after training, it generates 5 images for each test prompt (`data/artists.txt`,
  `data/pokemon.txt`) into `runs/<model>/<subset>-<prior weight>/results/`, to compare the effect by eye.

## Run it

```
pip install yacs accelerate transformers diffusers safetensors bitsandbytes pandas
python main.py --config configs/artists_with_preservation.yaml
```

Four configs are included: `artists_with_preservation`, `artists_without_preservation`, `pokemon_with_preservation`
and `pokemon_without_preservation`. Training uses 8-bit AdamW and gradient checkpointing on a single GPU.
`text_to_image_sd2_model.ipynb` runs the artist config on Google Colab.

## Fixes after review

Gradient clipping received an already-consumed parameter generator and never clipped (now a list); generated prior
images overwrote existing ones; the evaluation after the first epoch used the base model; the default model id in
`utils/config_helper.py` was rejected by the trainer; blank lines in a prompt file and missing Pokémon types could
crash the data loaders. Cluster job scripts from the course, which pointed to configs and datasets that are not part
of this project, were removed.
